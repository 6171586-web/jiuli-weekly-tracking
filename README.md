# Divis AI 每周跟踪 · 璞理九里一号

从用户申购确认日（2026-04-09）起，跟踪璞理九里一号个人持仓收益、
中证1000同期收益、周度超额收益与累计超额收益。

## 计算口径

- 个人持仓以100万元申购金额为起点。
- 中证1000以申购确认日收盘点位为起点。
- 2026-06-30分红按托管邮件中的实际新增份额复权。
- 每周数据来自托管估值邮件；网页按周更新。

## 本地运行

```bash
npm install
npm run dev
```

## 云端自动更新

GitHub Actions 每周一北京时间10:00检查QQ邮箱；如果没有新净值，11:00再检查一次。
发现新邮件后，流程会读取单位净值和份额、取得同日中证1000收盘数据、更新
`data/tracker.json`，并由GitHub Pages自动发布。

仓库需要配置两个Actions机密：

- `QQ_EMAIL`：QQ邮箱账号。
- `QQ_AUTH_CODE`：QQ邮箱IMAP授权码。

机密只由GitHub Actions读取，不写入源码、网页或构建日志。

## GitHub Pages构建

```bash
npm run build:pages
```

推送到 `main` 后，GitHub Actions 会自动发布网页。

> 本项目仅用于个人持仓记录与相对表现核对，不构成投资建议。
